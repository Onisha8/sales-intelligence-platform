# AI-Powered Sales Intelligence Platform

An end-to-end sales analytics and forecasting platform built to help business users analyze performance, predict future sales, and generate decision-ready insights.

## What this project does
- Forecasts sales trends using time-series and machine learning approaches
- Organizes analytics workflows using dbt and reproducible pipelines
- Supports scalable execution with Docker-based setup
- Delivers business-facing outputs for performance monitoring and decision support

## Why this project stands out
This project combines analytics engineering, forecasting, and business intelligence in one system. It is designed as a practical sales decision-support platform rather than a single notebook or isolated model.

## Tech Stack
Python • dbt • Docker • Forecasting • Data Pipelines • Business Intelligence
